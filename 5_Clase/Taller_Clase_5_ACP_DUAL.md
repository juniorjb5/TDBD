# Taller Clase 5 — ACP Dual

**Objetivo.** Usar ACP y ACP Dual para resumir varias variables cuantitativas, interpretar las dimensiones principales y evaluar si la estructura cambia entre grupos conocidos.

**Entrega.** Informe máximo de 5 páginas, en grupos de 3–4 estudiantes.

## Pasos mínimos

1. Presenten el contexto, la base de datos y las variables cuantitativas activas.
2. Identifiquen una variable cualitativa que pueda funcionar como grupo de comparación.
3. Realicen un ACP global sobre las variables cuantitativas.
4. Reporten la varianza explicada por las dos primeras dimensiones.
5. Interpreten las variables que más contribuyen a Dim.1 y Dim.2.
6. Construyan un ACP Dual usando la variable cualitativa como factor de agrupación.
7. Comparen si el papel de las variables cambia entre grupos, usando gráficos y coordenadas parciales.
8. Opcionalmente, hagan una segmentación con k-means usando las coordenadas factoriales del ACP.
9. Cierren con una decisión de negocio concreta.

## Pregunta guía

¿El ACP global era suficiente o los grupos muestran estructuras diferentes que cambian la interpretación?

## Recomendación

No llenen el informe de tablas largas. El valor del taller está en explicar con claridad:

- qué representan las dimensiones;
- qué variables las construyen;
- qué cambia cuando se comparan grupos;
- qué decisión se puede tomar con esa lectura.
