# Taller Clase 3 — Regresión cuantílica

**Objetivo.** Comparar un modelo lineal promedio con modelos cuantílicos para mostrar si una decisión cambia al mirar p10, p50 y p90.

**Entrega.** Informe máximo de 5 páginas, en grupos de 3–4 estudiantes.

## Pasos mínimos

1. Presenten el contexto, la base y la variable respuesta.
2. Justifiquen por qué la variable respuesta se beneficia de mirar cuantiles.
3. Hagan descriptivos: media, mediana, p10 y p90.
4. Estimen un modelo OLS como benchmark.
5. Estimen regresión cuantílica para al menos tres cuantiles: 0.10, 0.50 y 0.90.
6. Comparen una variable clave entre OLS y QR.
7. Cierren con una decisión de negocio concreta.

## Pregunta guía

¿El modelo promedio era suficiente o estaba ocultando una historia importante en la parte baja o alta de la distribución?
